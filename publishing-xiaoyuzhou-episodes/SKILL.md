# Publishing Xiaoyuzhou Episodes

在小宇宙**已有托管节目**上创建并提交单集。没有官方开放 API，也不要使用非官方接口；走官方主播后台（或官方文档写明的 Studio「发布到小宇宙」）。未得到明确授权前，不要创建新节目、不要上传或点「创建」、不要改节目设置里未要求的字段、不要删除节目、不要退出登录、不要改动其他节目。

下列表单限制来自 2026-11-10 在主播后台「创建单集」页面上的核对，不是完整官方手册。页面文案若与下文不一致，以当时页面为准。

## Choose A Mode

| 模式 | 边界 | 外部写操作 |
|---|---|---|
| `inspect-only` | 查看节目、未保存表单和页面限制 | 无 |
| `prepare-only` | 准备音频、标题、简介和 Show Notes，不提交 | 无 |
| `publish` | 补简介（如需要）、上传音频并点「创建」 | 必须先有明确授权 |

意图不清时默认 `inspect-only` 或 `prepare-only`。用户说「全权交给你」「发布」「提交」「创建」才进入 `publish`。

## Official entry points

- 统一登录：`https://accounts.xiaoyuzhoufm.com/login`（手机验证码或扫码；常见不是账号密码）
- 主播后台节目列表：`https://podcaster.xiaoyuzhoufm.com/podcast`
- 某节目主页：`https://podcaster.xiaoyuzhoufm.com/podcast/<showId>`
- 单集管理：`https://podcaster.xiaoyuzhoufm.com/podcast/<showId>/episode`
- 创建单集：`https://podcaster.xiaoyuzhoufm.com/podcast/<showId>/episode/create`
- 单集数据页：`https://podcaster.xiaoyuzhoufm.com/podcast/<showId>/episode/<episodeId>/stats`
- 节目公开页：`https://www.xiaoyuzhoufm.com/podcast/<showId>`
- 单集公开页：`https://www.xiaoyuzhoufm.com/episode/<episodeId>`

账号下可能有多个节目。先确认目标节目名称再进入，不要点「+」新建，也不要打开其他节目。

托管与 RSS：后台首页和「节目设置」里未必写「托管」或「RSS」。若有原生「创建单集」上传和资源库、节目设置里也没有 RSS 地址，按托管节目处理。RSS 导入节目不要用这条上传路径，除非页面明确提供同等入口。

官方博客还提到 Studio（`https://studio.xiaoyuzhoufm.com`）可将成片「发布到小宇宙」，并可能自动对齐响度。本流程默认走主播后台「创建单集」。用户指定 Studio 时再改走 Studio，不要混用两条路径各提交一次。

登录过期时停在登录页，把当前 URL 告诉用户，由用户完成验证码或扫码。不要猜测或填写登录凭证。登录完成后从目标节目继续，不要从中断的登录任务直接恢复。

## Prepare the episode

提交前备齐，并先核对音频是否符合当时页面限制：

- 目标节目名称（以及已知的 `showId`）
- 音频文件路径
- 单集标题
- Show Notes 文稿（纯文本，不放非官方外链）
- 是否将「本音频为 AI 生成」打开（语音合成或 AI 生成的音频应打开）
- 立即提交还是定时发布

音频（必传，2026-11-10 页面）：WAV / MP3 / M4A；最大 2GB；码率不低于 96kbps。接受类型包括 `audio/wav`、`audio/x-wav`、`audio/mpeg`、`audio/mp3`、`audio/x-m4a`。页面未写时长上限。提交前用本机工具确认格式、体积和码率。

视频（可选，同一「上传播客」弹窗）：MP4 / MOV / MPG；最大 10GB；最长 12 小时；建议比例 16:9 / 9:16 / 3:4 / 4:3；1080p 源不超过 25 Mbps，4K 源不超过 35 Mbps；编码 H.264 High Profile。页面建议视频与音频保持相同时长和音轨，不一致时仍可上传播放。默认不传视频，除非用户要求。

单集封面可选。文件选择器接受 `image/jpeg,image/png,image/webp`。页面未必写出像素或体积上限。未要求时沿用节目封面，不要擅自替换。

Show Notes：编辑器可能提示不再支持自定义二维码、淘口令和非官方外链，应使用官方转化组件。链接按钮可能是禁用的。不要把电报、X、GitHub 等外链写进正文；需要指出同步渠道时只用名称，不放 URL。若提交被拒，只去掉违规片段后重试一次。

定时发布默认关闭。打开后日期选择可能只允许当天起约 14 天；更早或更晚的日期会禁用。未要求定时则保持关闭。

## Inspect or complete the show

打开目标节目主页和「节目设置 → 节目信息」。可能弹出完善节目信息的欢迎窗。

`inspect-only`：只看，需要关掉弹窗时用「稍后再说」，不要保存。

`publish` 且简介为空：写入用户认可或事先备好的简介，然后点「保存更改」（仅在按钮可用时）。不要改节目名称、封面、主题色、主播名，也不要编造联系方式或资质认证。保存后可能提示「节目资料正在审核，修改将在审核完成后生效」；请再打开设置或公开页确认简介是否已显示。若保存按钮仍不可用，记录还缺哪一项，在不擅自补其他字段的前提下，仅在用户已授权发布时继续创建单集。

## Create the episode

仅在 `publish` 且已获授权时执行。

1. 打开「内容管理 → 创建单集」（或创建页 URL）。信息弹窗只点「我知道了」。
2. 上传指定音频为必传「音频文件」，等到上传成功（可见文件名、时长和「重新上传」）。不要选错文件，默认不传视频。
3. 填写精确标题。将 Show Notes 粘贴为纯文本。投票、征稿、追光、创作声明等可选项默认留空。
4. 按事先约定开关「本音频为 AI 生成」和「定时发布」。
5. 勾选「阅读并同意《小宇宙创作中心服务协议》」。页脚通常只有「创建」，没有单独的「草稿」或「发布」。
6. 点「创建」。若出现确认框，在已获发布授权时确认。

2026-11-10 实测：「创建」后可能没有确认框，站点直接进入新单集数据页。状态可能是「转码中」和「单集审核中」，不是草稿，也尚未对外可听。单集列表会出现该标题，发布日期为提交当日，徽章为「单集审核中」。此时公开单集页可能显示「找不到了」，这是审核完成前的预期情况，不要当成创建失败而重复提交。

离开未保存表单时，浏览器可能弹出离开确认；在未授权保存时不要保存。

## After submit

分别记录并报告，不要互相替代：

- 节目简介是否已保存，以及是否仍在资料审核
- 音频是否上传成功（文件名、时长）
- 是否已点「创建」，以及随后的页面原文（转码中、单集审核中、草稿、已发布、被拒等）
- 后台单集 URL、公开节目 URL、公开单集 URL
- 公开页是否已可播放；若仍是「找不到了」，如实说明审核完成前为预期

未获授权不要自动建立周期性检查。若需要盯审核，按用户要求设置有截止时间的检查：仍在转码或审核且公开页仍不可听时保持安静；通过、被拒或到期仍无结果时再通知一次并结束盯梢。

不要把「已提交审核」说成「已上架」。公开页可打开并播放后，才报告已对外发布。不要擅自修改每日信息源例程或其他发布渠道。

## Common mistakes

- 未授权就点「创建」，或把「研究发布流程」当成发布授权
- 用非官方 API 或第三方上传接口代替主播后台
- 在节目选择页点「+」新建节目，或改到其他节目
- 把 RSS 节目当成托管节目上传
- 在 Show Notes 里放非官方外链、自定义二维码或淘口令
- 看到公开页「找不到了」就再次创建，造成重复单集
- 把「转码中 / 单集审核中」说成已经上架
- 登录过期时自行填写验证码或密码
- 修改或删除未要求改动的节目资料，或在完成后退出登录
