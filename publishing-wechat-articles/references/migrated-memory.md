# Migrated Editorial Memory

这是从 Hermes 工作区和历史公众号工作记录中提炼的可复用规则。它是项目内的安全
经验快照，不包含个人路径、Cookie、Secret、聊天 ID 或表格 ID；事实、版本和远端
字段仍需在当前任务中重新验证。

## 频道与内容

- 技术类内容使用 AICoder 频道、极客黑主题，强调官方资料、工程判断、版本/API、
  实测边界、代码和避坑信息。
- 育儿类内容使用育儿育己频道、橙心主题，强调科学依据、适用年龄、具体话术、行动
  清单和专业求助边界。
- AI 辅助写作必须有个人分析、判断、实操或其他原创增量；不能照搬来源、伪造经历
  或把模板化改写当原创。

## 发布与验证

- 交接以 HTML 公网链接为主，消息只发送标题、摘要、封面 URL 和 HTML URL；不要把
  Markdown 正文拆成多条消息。
- OSS 上传前检查代理和目标配置，上传后读取公网 URL，比较 MIME、字节或 SHA-256；
  回读失败时不重复创建远端对象或消息。
- 飞书表格写入前先读取当前字段定义，字段名和字段类型以当次远端 schema 为准；
  `是否已发布` 只写布尔值 `false`，草稿或投递不等于公众号公开发布。
- 技术号和育儿号分别路由，不能因为当前登录账号或旧脚本默认值而混用目标。

## 研究与审核

- 普通社交媒体帖子只能作为线索；关键事实应补充官网、文档、发布说明或可靠的第二
  来源，并在 `research.json` 中记录来源状态、断言类型和限制。
- 动态页面正文或图片缺失时标记为不完整；不能根据标题、搜索摘要或 HTTP 200 猜测
  内容。
- 自动审核通过后仍需人工检查事实、图片、排版、版权、标题承诺和专业边界。
- 研究材料、历史草稿和作者经验只能作为输入，不能覆盖当前项目的授权边界或安全门。
